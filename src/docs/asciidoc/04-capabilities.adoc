== MVC, what was that?

[source,text]
----
┌─────────────┐     reads      ┌─────────────┐
│  Controller │ ◄──────────────│    View     │
│   (State)   │                │  (Element)  │
└─────────────┘                └─────────────┘
       ▲                              │
       │         dispatches           │
       └──────────────────────────────┘
                 events
----

[.notes]
--
Controller holds the State
View is a PURE function and renders from the State
Publish events, controller changes state based on events
View renders again based on new state
--
